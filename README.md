### Smart Season Chain Resolution

Other apps show you "Season 1" for a 500-episode franchise and call it a day. We **recursively traverse the entire AniList PREQUEL/SEQUEL graph** to build the complete franchise timeline.

```js
// Click on ANY entry in a franchise — we find them ALL.
// Example: User clicks "Naruto Shippuden"

const seasonChain = await getAnimeSeasonChain(animeId);

// Result:
// S1: Naruto              (220 eps) — AniList #20
// S2: Naruto Shippuden    (500 eps) — AniList #1735  ← you are here
// S3: Boruto              (293 eps) — AniList #97938

// Each season has its OWN AniList ID, MAL ID, episode count, status, year.
// Switching seasons loads the CORRECT streaming sources for THAT entry.
```

### State Management Philosophy

```jsx
// No Redux. No Zustand. No MobX. No Jotai. No Recoil.
// Just React Context + useReducer. Because we don't need a library
// to manage state when we actually understand how React works.

const AppContext = createContext();

function appReducer(state, action) {
  switch (action.type) {
    case 'SET_SECTION':        // Navigate between 14 sections
    case 'SET_THEME':          // Dark ↔ Light (saved to localStorage)
    case 'ADD_TO_COLLECTION':  // Add movie/show/anime with status + rating
    case 'REMOVE_FROM_COLLECTION':
    case 'UPDATE_ITEM_STATUS': // Watching → Completed → Dropped
    case 'SET_ACHIEVEMENTS':   // 108 unlockable achievements
    case 'ADD_NOTIFICATION':   // Toast queue with auto-dismiss
    case 'UPDATE_RESUME':      // S2E7 → pick up where you left off
    // ... every action you could ever need
  }
}
```
